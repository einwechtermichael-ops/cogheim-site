World of Cogheim / Vector

Strider Class

Vector

Eight legs, precision architecture, and a silhouette built around bio-circulatory systems and signal warfare — a Strider that reads more like a living organism than a machine.

HeritageAsian
ScaleLarge
IdentityPrecision, signal warfare, bio-systems
Hull Speed14 km/h

Being upfront: Vector has the least locked of any of the five classes right now. No deck-by-deck interior spec exists yet, no crew stations, no coded system. What follows is genuinely what's real, and a larger-than-usual proposed section past that — clearly marked, because there's more open space here than on the other four class pages.

Locked Canon

What's Actually Real

  • Eight-Legged Precision

    Vector moves on eight legs built for exact placement, not raw speed — ties at 14 km/h with Grindwalker for the fastest hull class, but the identity is precision, not just pace.

  • Bio-Circulatory Systems

    Vector's defining internal identity: systems that read as circulatory rather than mechanical — something flows through this hull the way it would through a living thing.

  • Signal Warfare

    Part of Vector's combat identity, distinct from the other four classes' more physical approaches to conflict.

  • Precision Elevated Deck

    Every Strider class has its own airfield architecture. Vector's reads as a precision elevated platform, not the improvised or industrial styles of the other hulls.

  • The Spire

    Every Strider's highest, always-unmarked point. On Vector, it's a hidden passage built into a palace tower wall — you have to already know it's there.

  • Five Canonical Renders

    Vector's five locked concept pieces are the visual foundation for everything on this page — the same five images in the gallery below.

Design Proposal — Not Yet Founder-Locked

What We're Still Imagining

Almost everything below this line is proposed, not locked — Vector has more open space than any other class right now, so take this section as a genuine starting point for a real spec session, not a preview of one that's already happened.

If the ship's defining trait is a bio-circulatory system, the deck layout probably isn't organized around decks stacked like floors at all — it might make more sense organized like a circulatory system itself, with a central "heart" chamber the whole hull's power and signal routes back through, and everything else branching outward from there like vessels. That would give Vector something none of the other four classes have: an interior that doesn't read as rooms connected by hallways, but as one continuous system you're walking through the inside of.

Signal warfare as a combat identity suggests Vector's weak-spot and defense profile might work differently than a straightforward armor question — maybe the ship is genuinely hard to target cleanly at range because its own systems actively interfere with lock-on, and the real vulnerability only opens up at close range where interference stops helping. That's speculation worth testing, not a decision anyone's made.
