Five Books, One Pipeline: Finishing the Cogheim Quintet's First Drafts

Book III closed out, and Books IV and V went from open questions to full first drafts. No plot details here — just the actual production math of finishing a five-book series while also building the game it feeds.

PeriodLate June–July 2026
CategoryWorld & Lore
Books TouchedIII, IV, V

The game gets most of this devlog's attention because it's the part with build logs and test counts attached. The Cogheim Quintet — the five novels this whole world is actually built from — doesn't get that treatment often enough. It should. This stretch was one of the heaviest writing pushes of the project so far.

Book III Was Already Done. We Just Didn't Know It.

Going into this stretch, Book III: The Iron Meridian turned out to already be complete — a full ten-act arc, roughly 49,000 words, with the illustration prompts for every act already locked and the print pipeline already proven end to end. Sometimes the most useful thing a status check does is confirm you're further along than you thought.

That meant the real work of this period was ahead, not behind: Book IV and Book V, both still unwritten.

Writing Two Books Back to Back

Book IV went from an open act structure to a full draft, all ten acts. Book V followed the same path — a complete eleven-act first draft. Two full manuscripts, written back to back, on top of everything else this project has running at the same time.

The honest number: Book V's first pass landed short — about 34,200 words across 159 pages, against Book III's roughly 59,500 words and 208 pages. Not a story problem. A depth problem: more individual scenes than Book III, but each one running thinner than it needed to.

Fixing Depth, Not Length

The fix wasn't padding. It was going back through act by act and asking where a scene was reporting an event instead of living inside it, then rewriting from the inside. That pass took Book V from 159 pages to 221 — roughly 47,000 words across eleven acts — without adding new plot, just adding the room the existing plot needed to breathe.

Formatting cohesion got the same scrutiny. Books II, III, and IV all needed to read as one continuous series rather than three separately-formatted documents, so every print and EPUB build got checked against the same baseline before anything shipped.

The Pipeline Behind Five Books

None of this happens by hand-formatting a manuscript in a word processor. The print interiors run through a dedicated build: prose set at 14pt with proper line-height and margins matched across every book, illustration plates merged in at print resolution, page numbers applied programmatically, and the EPUB generated from the same source so both formats stay in sync instead of drifting apart.

Production note: a five-book series is also a five-book consistency problem — naming, formatting, page count, tone. The pipeline exists specifically so that problem gets caught by a build check, not by a reader noticing Book IV looks different from Book II.

What's Still Ahead

First drafts of all five books now exist. What's left is finishing work, not first-draft work:

  1. Expansion passes on any book that lands short of the series' established depth, the same way Book V did.
  2. Full illustrated builds — print PDF and EPUB — for every book, matched to one formatting standard.
  3. KDP publishing prep, including cover work and print specs, once page counts are final.
  4. A cross-series consistency pass checking names, terminology, and formatting hold across all five books at once.
